本项目是一个基于 Unity + VRChat SDK3 的模型/场景工程，定位为授权安全教学靶场，而不是公开可用的攻击工具，也不是用于规避平台审核的“免检模型包”。

授权范围仅包括：本地客户端/私人房间/测试账号/指定 Avatar/指定 World/指定实验网络环境。所有实验均在隔离环境、可审计、可回滚的条件下进行，不接入公开实例，不针对真实用户，不使用未授权资产。

靶场内容主要包括：示例 Avatar、World 场景、UdonSharp 教学脚本、动画与参数同步、PhysBones/Contacts、权限与资源校验用例、日志记录与回滚机制。课程目标是帮助学员理解 VRChat 模型/世界的构建、同步、权限边界、性能开销与资产供应链风险。

使用规则：仅限授权人员，仅限授权范围；禁止公开分发可能造成危害的模块；禁止攻击、骚扰、追踪真实用户；禁止绕过 VRChat ToS、SDK 许可或创作者授权；发现风险应按授权渠道披露。
