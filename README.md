同学们好，我是本课程项目的作者。这个 Unity 模型项目，我不把它只当作一个“模型展示”或普通 Demo，而是把它定义为一个**授权靶场**。它以 Unity 场景为载体，把 3D 模型、材质贴图、交互脚本、任务关卡、状态逻辑和日志记录组织成一个可控、可复现、可审计的教学演练环境。

在这个靶场里，所有模型、场景、脚本和接口均来自课程自制或已获授权的资源。它默认运行在本地或隔离实验网络中，不接入真实业务系统，不包含真实敏感数据，也不对公网开放。它的目的，是让大家在合法合规的前提下，理解系统结构、交互流程、状态变化和防护思路，而不是针对任何真实目标。

使用上，它遵循四个原则：**授权方明确、范围明确、时间明确、审计明确**。只有在本课程授权名单内、在规定时间窗口和指定关卡中，才可以进行操作、测试、演示和提交实验报告。禁止对未授权目标进行扫描、攻击、传播、商业化利用，禁止将靶场环境暴露到公网，禁止保存或传播任何真实敏感信息。
